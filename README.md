# Алгебра и геометрия — приложение для контрольной точки №3

Приложение на Python/Tkinter помогает подготовиться к **КТ №3** по курсу «Алгебра и геометрия» и закрывает важные демонстрационные части предыдущих контрольных точек.

## Что внутри

### 🧮 Калькулятор

- операции с матрицами: сложение, вычитание, умножение на число, умножение матриц, транспонирование, определитель, ранг;
- решение СЛАУ тремя способами: матричный метод, метод Крамера, метод Гаусса;
- операции с векторами: сложение, вычитание, умножение на число, скалярное, векторное и смешанное произведение;
- промежуточные шаги вычислений и понятные сообщения, если операция математически невозможна.

### 🎨 Лабораторная работа №1

В отдельной вкладке реализована программа замены цвета в растровом изображении:

1. загрузка изображения PNG/GIF/PPM/PGM;
2. выбор целевого цвета палитрой или настоящей пипеткой: нажмите «Пипетка» и кликните по пикселю на исходной картинке;
3. выбор нового цвета;
4. построение маски по цвету с настраиваемым допуском;
5. замена пикселей с сохранением светлых и тёмных оттенков выбранной области;
6. последовательное применение новых замен уже к текущей версии результата;
7. отмена и возврат изменений;
8. сохранение результата.

Для быстрой демонстрации есть кнопка создания демо-картинки прямо в приложении. Просмотр изображений масштабируется под окно, а режим «100% + прокрутка» позволяет рассмотреть большую картинку целиком через полосы прокрутки.

### 📌 Мини-тренажёр по теме «Прямая и плоскость»

Вкладка с карточками формул и чек-листом для защиты КТ №3: уравнения прямой и плоскости, угол между плоскостями, расстояние от точки до плоскости.

## Быстрый старт

### Требования

- Python 3.10+
- Tkinter из стандартной поставки Python
- Дополнительные пакеты не требуются

### Запуск приложения

```bash
python3 app.py
```

### Запуск тестов

```bash
python3 -m unittest discover -s tests -v
```

## Формат ввода

- Матрица: `[[1,2],[3,4]]`
- Вектор: `[1,2,3]`
- Скаляр: `2.5`
- Для смешанного произведения: `A` и `B` — первые два вектора, поле скаляра — третий вектор `C`, например `[0,0,1]`.

## Удобные фишки

- вкладки по сценариям: калькулятор, лабораторная, теория;
- быстрые примеры для заполнения полей;
- тёмная область вывода результатов;
- демо-изображение для лабораторной без поиска файла на компьютере;
- настоящая пипетка для выбора цвета прямо с исходной картинки или текущего результата;
- замена цвета с сохранением оттенков, чтобы тени и полутона не превращались в один плоский цвет;
- история изменений с кнопками «Отменить» и «Вернуть»;
- масштабирование предпросмотра под окно, режим 100% и прокрутка больших изображений;
- счётчик заменённых пикселей;
- случайные карточки формул для подготовки к устным вопросам.
